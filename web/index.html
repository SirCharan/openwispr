FAQ

Questions, answered.

Why does macOS block the app on first open?

The build isn't notarized yet. Right-click Whispr.app → Open → Open once; it opens normally after that.

How big is the download?

The app is under 2 MB. On first launch it downloads the Whisper model (~1.5 GB, one time). Smaller models are available in Settings.

Does any audio or text leave my Mac?

No. Recording, transcription, and cleanup run on-device. The only network calls are the one-time model download and — only if you enable it — your own AI provider.

Do I need Ollama or an API key?

No. Dictation and meetings work fully without AI. If you want summaries or tone rewrites, run Ollama locally (stays offline) or add an OpenAI/OpenRouter key.

What permissions does it need?

Microphone (to hear you), Accessibility (to paste at your cursor), and Screen Recording only if you use meeting capture (that's how macOS exposes system audio).
